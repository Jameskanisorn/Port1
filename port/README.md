# Portfolio — คณิศร หอมกลิ่น (เจมส์)

เว็บพอร์ตโฟลิโอสไตล์มินิมอล ธีมสีขาว สำหรับ Video Editor
เขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## เปิดดูเว็บไซต์

ดับเบิลคลิก `index.html` ได้เลย (แนะนำให้เปิดผ่านเบราว์เซอร์ Chrome / Edge / Safari)

> หมายเหตุ: ภาพปกวิดีโอและฟอนต์โหลดจากอินเทอร์เน็ต ถ้าเปิดแบบออฟไลน์
> ภาพปกอาจไม่แสดง แต่โครงเว็บยังใช้งานได้ปกติ

## โครงสร้างไฟล์

```
port/
├─ index.html                  ← หน้าเว็บหลัก (แก้ข้อความทั้งหมดที่นี่)
├─ README.md                   ← ไฟล์ที่คุณกำลังอ่าน
├─ example-data.txt            ← ข้อมูลต้นฉบับ
├─ personal-portfolio.jpg      ← รูปต้นฉบับ (สำรอง)
└─ assets/
   ├─ css/
   │  └─ style.css             ← สไตล์ทั้งหมด แบ่งเป็นหมวดตามหมายเลข
   ├─ js/
   │  ├─ works-data.js         ← ข้อมูลผลงาน (แก้/เพิ่มคลิปที่นี่)
   │  └─ main.js               ← การทำงาน: เมนู, วิดีโอ, animation
   └─ img/
      └─ personal-portfolio.jpg ← รูปโปรไฟล์ที่เว็บใช้จริง
```

## วิธีแก้ไขข้อมูล

| ต้องการแก้ | ไปที่ |
|---|---|
| ชื่อ, ตำแหน่ง, แนะนำตัว | `index.html` → ส่วน `#home` และ `#about` |
| บริการ / สิ่งที่ทำ | `index.html` → ส่วน `#services` |
| อีเมล, เบอร์โทร, LINE | `index.html` → ส่วน `#contact` |
| ลิงก์โซเชียล | `index.html` → ส่วน `#contact` |
| เพิ่ม/ลบคลิปผลงาน | `assets/js/works-data.js` |
| สี, ฟอนต์, ระยะห่าง | `assets/css/style.css` → หัวข้อ `:root` |
| รูปโปรไฟล์ | วางทับไฟล์ `assets/img/personal-portfolio.jpg` |

### เพิ่มผลงานใหม่

เปิด `assets/js/works-data.js` แล้วเพิ่มบล็อกในหมวด `long` (คลิปยาว)
หรือ `short` (คลิปสั้น) เช่น

```js
{
  id: "OBi0TRJlEZc",                       // รหัสวิดีโอจากลิงก์ YouTube
  start: 40,                               // (ไม่บังคับ) เริ่มเล่นที่วินาทีที่ 40
  title: "รีวิว Honda UC3 รถไฟฟ้าล้วน",    // ชื่อสั้นบนการ์ด
  fullTitle: "ชื่อเต็มจาก YouTube",         // tooltip + ชื่อในเครื่องเล่น
  note: "รีวิวรถไฟฟ้า · YouTube",           // หมวดหมู่ย่อยใต้ชื่อ
  badge: "YouTube",                        // ป้ายมุมภาพ
},
```

รหัสวิดีโอคือส่วนหลัง `watch?v=` หรือหลัง `/shorts/` ในลิงก์ YouTube

## ฟีเจอร์ที่มี

- Responsive รองรับมือถือ แท็บเล็ต และเดสก์ท็อป
- คลิกการ์ดผลงานเพื่อเล่นวิดีโอในหน้าเว็บ (ไม่ต้องออกไป YouTube)
- ปุ่มคัดลอกอีเมล และปุ่มกลับขึ้นด้านบน
- เมนูมือถือ และไฮไลต์เมนูตามตำแหน่งที่เลื่อนอยู่
- แอนิเมชัน: Hero ไล่ลำดับ, ตัวเลขสถิติวิ่ง, การ์ดค่อย ๆ โผล่ทีละใบ,
  รูปโปรไฟล์ขยับตามเมาส์, การ์ดเอียงเล็กน้อย, แสงเรืองตามเมาส์,
  แถบความคืบหน้าการเลื่อนหน้า และภาพปกค่อย ๆ ปรากฏ
- ปิดแอนิเมชันที่เคลื่อนไหวมากโดยอัตโนมัติ ถ้าเครื่องตั้งค่า Reduce motion
- ไม่ใช้ไลบรารีภายนอก จึงโหลดเร็วและดูแลง่าย
